✨ 2. The WOW Features — How They Work & Tech Stack

1. Passwordless Web3 MetaMask Authentication (EIP-191 / SIWE) Gasless Web3

What it does: Allows users to authenticate instantaneously with MetaMask on mobile with zero passwords, or link a cryptographically verified wallet address to their profile.

How it works behind the scenes:

  1. User taps Continue with MetaMask in the Expo mobile app.
  2. The app requests a challenge from GET /api/auth/nonce?address=0x.... The backend creates a 16-byte random hex nonce with a strict 5-minute time-to-live.
  3. The mobile app deep-links to MetaMask using @metamask/sdk (with fallback scheme smartassets://).
  4. The user signs the challenge message using EIP-191 personal_sign. Crucially, this is gasless (costs 0 ETH) and triggers no on-chain transaction.
  5. The app posts { walletAddress, signature, nonce } to POST /api/auth/wallet-login.
  6. The backend calls ethers.verifyMessage(), recovering the ECDSA public address. If verified, the nonce is burned (preventing replay attacks) and an authentic Supabase JWT session is minted via an admin magiclink OTP exchange.

Technologies: React Native, Expo SDK 54, @metamask/sdk, ethers.js v6, Supabase Auth Admin API.

2. Multimodal AI Vision Gatekeeper & Anti-Counterfeit Scanner Gemini Multimodal AI

What it does: Acts as an automated marketplace gatekeeper, analyzing collectible photos to prevent synthetic fakes, category fraud, and misvalued listings.

The 4-Tier Inspection Pipeline:

  1. Tier 1 (Pre-flight & Resolution): Inspects byte headers and rejects corrupted images or resolutions below 300x300px.
  2. Tier 2 (Synthetic Deepfake Detection): Scans frequency and metadata patterns. If probability of AI-generation (Midjourney/DALL-E) exceeds 0.82, the upload is blocked.
  3. Tier 3 (Google Gemini Flash Inspection): Gemini Flash analyzes visual hallmarks, logos, serial number typography, and classifies the category (blocking mismatches like shoes listed as watches).
  4. Tier 4 (Market Oracle Appraisal Bands): Queries live ZAR/USD valuation bands (Floor, Median, Fair Market Value) and maps to on-chain ERC-721 token provenance.

Technologies: Google Gemini Flash Vision API, Sharp/Buffer inspection, aiVisionGatekeeper.js, marketOracleService.js.

4. Fractional Co-Ownership & Real-Time Portfolio Snapshots High-Liquidity Engine

What it does: Splits multi-million Rand collectibles into fractional co-ownership units (shares), accompanied by a time-series portfolio analytics engine.

How it works:

  1. Sellers designate whole or fractional listings (total shares, cost per unit).
  2. Purchases atomically update assets.shares_sold and log fractional holdings into public.investment_positions.
  3. The portfolioSnapshotService.js aggregates whole holdings, fractional positions, available cash, and escrow balance into daily snapshots in public.portfolio_snapshots (with user_id + snapshot_date unique constraint).
  4. The mobile app renders interactive yield and trendline charts over 24h, 7d, 30d, and 1y intervals.

Technologies: investmentPositionService.js, portfolioSnapshotService.js, React Native SVG charts.

5. 3D glTF Mesh Generation & AR "Live Room Preview" Spatial Computing

What it does: Enables buyers to project interactive 3D digital twins of luxury assets directly into their room using Augmented Reality before purchasing.

How it works: 2D photos are turned into 3D meshes using Tripo AI. The raw 500k-polygon mesh is compressed by the backend's modelOptimizer.js (via @gltf-transform/core and meshoptimizer) down to ~35,000 triangles and ~2.5MB WebP textures for smooth 60 FPS mobile rendering with Expo Camera.

Technologies: Tripo 3D AI, @gltf-transform/core, meshoptimizer, Expo Camera, Device Sensors.

🔒 3. System Security Architecture (The 6 Defensive Rings)

SmartAssets enforces defense-in-depth across six distinct architectural boundaries:

Ring 1: Network & HTTP Gateway Hardening

Helmet.js: Enforces Content-Security-Policy (CSP), X-Frame-Options: DENY (anti-clickjacking), HTTP Strict Transport Security (HSTS), and MIME-sniffing prevention.

Rate Limiter Middleware: Protects authentication endpoints against brute-force password and wallet guessing, and limits file upload buffers to mitigate Denial of Service (DoS).

Ring 2: Deep SQL Injection & PostgREST Sanitizer

Located in securityMiddleware.js: Recursively inspects every key and value in incoming request bodies, query strings, and headers against comprehensive regex patterns:

  • Union-based injection: UNION SELECT
  • Tautology and boolean bypass: ' OR 1=1 --
  • Destructive DDL/DML: DROP, TRUNCATE, DELETE FROM
  • Time-based blind SQLi: pg_sleep(), WAITFOR DELAY
  • System catalog enumeration: information_schema, pg_shadow

Offending payloads are immediately rejected with HTTP 400 and logged to the security audit ledger.

Ring 3: Session Security & Financial Inactivity Watcher

Token Revocation Blacklist: Invalidated tokens are instantly added to a persisted revocation list upon logout, preventing replay of stolen JWTs.

InactivityWatcher.js: On mobile devices, unattended sessions present a major security hazard. A transparent PanResponder captures passive screen gestures:

  • If 4 minutes and 30 seconds elapse without interaction, a 30-second warning countdown banner appears.
  • If no touch occurs by 0 seconds, session tokens in AsyncStorage are wiped and the user is redirected to the login screen.

Ring 4: Bank Withdrawal Email OTP Verification (2-Factor Guard)

Implemented in withdrawalVerificationService.js:

  • Withdrawals require verified bank accounts and trigger a cryptographically secure 6-digit OTP via TLS SMTP email.
  • Strict 120-Second Lifespan: Enforces an exact 2-minute server-clock expiry.
  • Single-Attempt Burn: Entering an incorrect OTP immediately destroys the challenge, completely blocking automated guessing attacks.
  • Concurrency Mutex Locks: Prevents race-condition double withdrawals per user.

Ring 5: Institutional 3-Doc KYC & Database Row-Level Security (RLS)

Row-Level Security (RLS): Supabase PostgreSQL isolates sensitive user portfolios, KYC documents, and bank details at the kernel level (auth.uid() = user_id).

3-Document KYC: High-value transactors must provide Government ID, Tax Certificate, and Proof of Residence, stored in private gated buckets with short-lived signed URLs.

Ring 6: Solidity Smart Contract Defense

All smart contracts inherit OpenZeppelin's battle-tested ReentrancyGuard with the nonReentrant modifier to neutralize re-entrancy attacks during ETH withdrawals. Built on Solidity ^0.8.24 with native overflow protection.

❓ 5. Anticipated Judges' Questions & Winning Answers

Q1: "Why do you need blockchain and MetaMask instead of just PostgreSQL?"
"A centralized database has a single point of failure and administrator trust issues. Luxury collectibles require immutable, tamper-proof provenance. By minting an ERC-721 certificate on Ethereum Sepolia, the asset's history and chain-of-custody milestones are permanently verifiable by anyone. Furthermore, with MetaMask and smart contract escrow, the platform never holds custody of buyer funds—they are locked in verified Solidity code with ReentrancyGuard and released only upon physical appraisal sign-off."
Q2: "Does MetaMask authentication cost real gas fees?"
"No! We implemented EIP-191 cryptographic challenge-response authentication. The user signs an off-chain challenge string with their private key. The backend recovers the public key using elliptic curve cryptography (ethers.verifyMessage). It costs zero gas and executes instantaneously."
Q3: "How do you detect AI-generated fake luxury assets?"
"Our AI Vision Gatekeeper runs a 4-tier inspection pipeline. Tier 2 examines frequency anomalies and image metadata; if synthetic probability from Midjourney or DALL-E exceeds 0.82, it is rejected immediately. Tier 3 uses Google Gemini Flash to inspect hallmarks, engravings, serial number typography, and category alignments against authentic standards."
Q4: "What happens if a user leaves their mobile app open unattended?"
"We built an Inactivity Watcher utilizing React Native's PanResponder. It captures passive touch gestures across the app. After 4 minutes and 30 seconds of inactivity, it displays a 30-second warning countdown. If no touch occurs, the session tokens are wiped and the user is securely logged out to prevent session hijacking."
Q5: "How does your withdrawal system prevent unauthorized payouts?"
"Withdrawals require institutional KYC, an approved bank account, and a single-use 6-digit OTP code sent over secure TLS to the account holder's email. The OTP has a strict 120-second lifespan and a single-attempt burn policy—a single incorrect attempt destroys the challenge immediately."
